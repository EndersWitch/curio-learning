INTRO: Every sentence does a job. It can give information, ask for it, give an order or show strong feeling. These four jobs give us the four <strong>sentence types</strong>.

@@CARD
TYPE: definition
TITLE: What is a sentence?
CONTENT: A sentence is a group of words that expresses a complete thought. It begins with a capital letter and contains a finite verb. In a command the subject you is understood.
EXAMPLE: The boy plays.
@@ENDCARD

@@CARD
TYPE: key_rule
TITLE: Statements and questions
CONTENT: A statement supplies information. A question asks for information.
EXAMPLE: Shaun is going to school.<br>Where is Shaun going?
@@ENDCARD

@@CARD
TYPE: key_rule
TITLE: Commands and exclamations
CONTENT: A command gives an order or an instruction. An exclamation expresses strong emotion such as surprise, fear, alarm or anger.
EXAMPLE: Do not enter through that door.<br>It's a ghost!
@@ENDCARD

@@CARD
TYPE: try_it
TITLE: Name the type
CONTENT: Name the type of this sentence. Close the door.
EXAMPLE: A command, because it gives an order.
@@ENDCARD

TESTED:

Match a sentence to its job
@@ENDLEVEL

INTRO: You have met <strong>sentence types</strong> before. This Grade 7 revision checks that you can name all four in exam-style sentences, including tricky ones where the wording hides the type.

@@CARD
TYPE: spot_difference
TITLE: The four sentence types
SIDE_A: Type
SIDE_B: Job
CONTENT: Statement | supplies information<br>Question | asks for information<br>Command (imperative) | gives an order or instruction<br>Exclamation | expresses emotion such as surprise, fear, alarm or anger
EXAMPLE: Shaun is going to school.<br>Where is Shaun going?<br>Do not enter through that door.<br>It's a ghost!
@@ENDCARD

@@CARD
TYPE: key_rule
TITLE: Look at the job, not the word
CONTENT: A question word does not always make a question. Decide what the sentence does. A polite request that asks for information is still a question, and a polite order is still a command.
EXAMPLE: I know what you mean. (statement)<br>What do you mean? (question)<br>Please close the window. (command)
@@ENDCARD

@@CARD
TYPE: step_by_step
TITLE: Naming the type
CONTENT: 1. Ask whether the sentence gives information, asks for it, gives an order or shows strong feeling.<br>2. Check the punctuation at the end.<br>3. Check whether the word order has changed.
EXAMPLE: Leave the room immediately!<br>It gives an order, so it is a command, and the exclamation mark adds force.
@@ENDCARD

@@CARD
TYPE: common_mistake
TITLE: Exclamation marks
CONTENT: An exclamation mark does not make every sentence an exclamation. A command can end with one to add force. An exclamation expresses emotion.
EXAMPLE: Leave the room immediately! (command)<br>It's a ghost! (exclamation)
@@ENDCARD
